# Darrell Rodriguez — UX Portfolio

A responsive static portfolio with six project case studies, an education summary, and LinkedIn contact links. Public files are in `dist/`. The original supplied files remain unchanged on the Desktop.

Case-study content comes from the actual `portfolio content` folder: Mood, Journey Through Design (GIT 540 Team 9), Rose Family Bakery POS, Loaded accessibility review, City of Phoenix wireframes, and AI Driving. Screens were exported from the supplied Figma files. Team screens are credited as shared outputs, with testing observations based on notes credited to Darrell. No unsupported impact metrics or client relationships are claimed.

Run `node build-portfolio.mjs` to regenerate the homepage and case studies from `portfolio-content.mjs`. The site has no build-time dependencies. `dist/gallery.js` progressively enhances image links with an accessible image viewer. The original four-page AI Driving website is in `dist/ai-driving/`; its contact form is explicitly a non-sending demonstration. The original design report is in `dist/documents/`.
